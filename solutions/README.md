# 선생님과 함께 — 고친 코드 예시 (교사용)

학생에게 먼저 보여 주지 않습니다. `main.py`의 해당 부분만 바꾸면 됩니다. VPyLab은 저장소의 `main.py` 하나만 읽으므로 이 폴더는 실습 화면에 나오지 않습니다.

## 1단계: 두 힘이 서로 지워질 때
'1. 바꿔 볼 숫자'에 두 줄을 더합니다.

```python
미는_빠르기 = 1        # 앞으로 미는 힘: 1초 동안 빠르기를 늘리는 양 (m/s)
당기는_빠르기 = 1      # 뒤로 당기는 힘: 1초 동안 빠르기를 줄이는 양 (m/s)
```

'2. 법칙'을 아래와 같이 바꿉니다. 멈추게만 하는 마찰과 뒤로 보낼 수도 있는 당기는 힘을 따로 계산합니다.

```python
def 한_걸음(빠르기, 위치):
    빠르기 = 빠르기 + (미는_빠르기 - 당기는_빠르기) * 시간간격   # 두 힘의 차이만큼 빠르기가 바뀌어요
    if 빠르기 > 0:
        빠르기 = max(빠르기 - 줄어드는_빠르기 * 시간간격, 0)       # 마찰은 멈추게 할 뿐이에요
    위치 = 위치 + 빠르기 * 시간간격
    return 빠르기, 위치
```

확인(줄어드는_빠르기 = 0, 출발 4 m/s): 둘 다 1이면 점 간격이 4 m로 유지됩니다. 미는 쪽만 1이면 간격이 4.5 · 5.5 · 6.5 m…로 늘고, 당기는 쪽만 1이면 4초 뒤 8 m에서 잠깐 멈췄다가 뒤로 돌아옵니다(코드는 위치가 −5 m보다 작아지면 멈춥니다). 이때 화면에는 '아직 멈추지 않았어요'가 나오는데, 학생과 함께 알림 문구를 고쳐 보는 것도 좋은 과제입니다.

## 2단계: 빠를수록 방해가 커지는 바닥
'1. 바꿔 볼 숫자'에 `비율 = 0.5`를 더하고, '2. 법칙'의 첫 줄을 바꿉니다.

```python
    빠르기 = 빠르기 - 비율 * 빠르기 * 시간간격   # 빠를수록 빠르기가 많이 줄어들어요
    if 빠르기 < 0.01:
        빠르기 = 0                               # 아주 느리면 멈춘 것으로 봐요
```

확인: 출발 빠르기가 4 m/s이고 비율이 0.5이면 약 12초 뒤 약 7.97 m에서 멈춥니다(참값은 출발 빠르기 ÷ 비율 = 8 m에 가까워집니다). 점 간격이 매초 같은 비율(약 0.61배)로 줄어듭니다.

## 3단계: 두 원반 나란히
- `한_걸음(빠르기, 위치, 줄어드는_빠르기)`처럼 줄어드는 빠르기를 매개변수로 받게 합니다.
- 원반 두 개의 `z` 위치만 다르게 설정하고(예: `vector(0, 0, -0.5)`, `vector(0, 0, 0.5)`), 길의 폭(`size`의 z)을 3 정도로 넓힙니다.
- `상태`에 빠르기 · 위치를 두 벌(`['빠르기1']`, `['빠르기2']` 또는 목록) 저장하고, 루프에서 각 원반에 대해 `한_걸음`을 호출합니다. 두 원반이 모두 멈추면 `달림`을 False로 바꿉니다.
- 확인: 카펫(4)과 얼음(1)의 원반을 함께 내보내면 1초 뒤 카펫의 원반은 2 m에서 이미 멈춰 있고, 얼음의 원반은 3.5 m에 있습니다. 두 원반이 모두 멈추면 각각 2 m와 8 m에 있습니다.
